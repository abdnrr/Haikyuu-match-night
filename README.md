# HAIKYUU!! — Match Night

An unofficial fan tribute page for Haikyuu!!, built with plain HTML, CSS and JavaScript (no frameworks).

**Features**
- Volleyball-themed layout with a scoreboard that follows your scroll
- Team scouting cards and hover-to-flip player cards
- A small spike mini-game with a score counter
- Rotating quotes

Haikyuu!! belongs to Haruichi Furudate and Shueisha.
